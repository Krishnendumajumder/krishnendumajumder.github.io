# Krishnendu Majumder Portfolio

Full-stack portfolio project built with React, TypeScript, Vinext, and the OpenAI Sites runtime.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The interface source is in `app/` and `components/`. Runtime and deployment configuration is in `vite.config.ts`, `next.config.ts`, and `.openai/hosting.json`.
